# Pilot recording checklist

Read this on your phone while you film. Tick each box as you go. About 30 minutes of filming.

## 1. What the pilot is for

This is a short first test with real phones, because the software has only been tried on computer-made data. We want to see if it can follow your hips and measure squat depth, and where it goes wrong.

## 2. What you need

- [ ] Two phones (a third helps) on tripods or something very stable
- [ ] The printed checkerboard (stick it flat on a stiff board)
- [ ] A ruler
- [ ] A torch (a phone torch is fine, but it must be a different phone from the two filming)
- [ ] A stick of known length
- [ ] A stool
- [ ] A few flat boards or books to raise the stool
- [ ] Tape (for a cross on the floor)
- [ ] A notebook and pen

## 3. Before filming

**Measure the board squares.** The board has 8 x 11 squares.
- [ ] Measure four squares in a row with the ruler. Divide by four. Do it along the long side and the short side. Write both in millimetres.

**Measure the rest.**
- [ ] Stick length: write it in centimetres.
- [ ] Thickness of each board or book: write each one down.

**Phones.**
- [ ] Charge them. Free up storage (1080p at 60 fps makes big files).
- [ ] Use the rear main camera, 1x, no zoom.
- [ ] Set 1080p at 60 fps if the phone allows it. Use the same on both phones.
- [ ] Turn off stabilisation, auto lens switching and auto framing.
- [ ] Lock focus and exposure if the phone lets you.
- [ ] Hold every phone upright (portrait). Use the same way up for every video.
- [ ] After you film the board, do not change the lens or the mode.

*Calibration* means filming the board so the software learns your phone's lens and where the phones stand.

## 4. Setting up the room

- [ ] Plenty of light.
- [ ] Wear fitted clothes so your hips can be seen.
- [ ] Put a tape cross on the floor. Stand on it at the start of every take.
- [ ] Face the same way in every take.
- [ ] Put both phones in front of you, about 45 degrees to the left and right, about 3 m away, lens about 1 m high, upright.
- [ ] Third phone (if you have one): directly to your side.
- [ ] Check each phone: your whole body stays in frame from standing to the bottom of the squat, with space around you. Points on the edge of the picture are thrown away.
- [ ] Do the lens clips (item 1 below) before you fix the phones in place, then do not touch the phones again. If one moves, redo the board-still clip.

## 5. The filming list

1. [ ] **Lens clip, phone 1 (about 60 seconds).** Hold the board in the centre, edges and corners of the picture. Tilt it left, right, up and down. Hold it near and far. Pause a moment at each place so it is sharp. Name it for the phone (cam1).
2. [ ] **Lens clip, phone 2 (about 60 seconds).** Same again (cam2). Third phone, if used: same again (cam3).
3. [ ] **Board held still (both phones recording at once).** Start both phones. Stand the board upright and level in the middle of the squat area, facing both phones. Use a spirit level if you have one. Hold it still for 3 to 5 seconds. Both phones must see the whole board. Write down the time you started each phone.
4. [ ] **Stick check, five places (about 10 seconds each).** Lay or stand the stick in five different places and directions in the squat area. Both phones must see both ends. This checks the software gets lengths right. Write down where each one was.
5. [ ] **Take A: stand still, then 6 normal squats (about 1 minute).**
6. [ ] **Take B: squat down to the stool alone, controlled pace.**
7. [ ] **Take C: stool raised by one measured board, controlled pace.**
8. [ ] **Take D: stool raised by more boards, controlled pace.** Repeat with different measured heights if time allows.
9. [ ] **Faster takes:** repeat B and one raised height at a faster pace.

**In every take (5 to 9):**
- [ ] Start all phones.
- [ ] Switch the torch on for about half a second where every phone can see it. This is the flash.
- [ ] Stand still for 10 seconds on the tape cross.
- [ ] Do your squats. Squat 1 sets your reference depth.
- [ ] Stand still for 2 seconds between squats.
- [ ] Touch the stool lightly and come straight back up.
- [ ] Say out loud, or write down, which height each squat was.
- [ ] Stand still, then flash the torch again.
- [ ] Stop all phones.

**How many:** 6 squats in take A. In the stool takes, 3 squats at each height. Raise the stool by about 2, 4, 6 and 8 cm, and measure what you actually add. Each stool take lasts about 30 to 40 seconds.

**Pace:** controlled is about 2 seconds down and 2 seconds up. Faster is about 1 second down and 1 second up.

## 6. What to write in the notebook

- [ ] Date, and the name of each take.
- [ ] Square size (both directions), stick length, thickness of every board.
- [ ] Phone model, resolution and frame rate for each phone.
- [ ] Which phone is cam1, cam2, cam3.
- [ ] For each take: pace, stool height (boards used) and any problems.
- [ ] Squat by squat: which height it was. Note any mistake, for example "slipped, ignore".

## 7. After filming

- [ ] Copy every video to the computer. Keep one folder per day, like `2026-11-16`, and put each take in its own folder (for example `take1`) with files named `cam1.mp4`, `cam2.mp4`. Do not rename or edit videos. Keep the lens and board clips as `cam1_lens.mp4`, `board_cam1.mp4` and so on.
- [ ] Do not delete the originals on the phones until Claude says all files are fine.
- [ ] Give Claude the notebook numbers (square size, stick length, board thickness) and the file names.
- [ ] **Label each squat from the video BEFORE you look at any software result.** For each squat write: match (same depth as squat 1), shallow, or unclear. Save these in a list like `configs/labels.example.csv`. Looking at the software first would make the test unfair.
- [ ] Copy the files by USB cable. When you plug the phone in, choose "File transfer" on the phone.
- [ ] Ask Claude to run the software.

## 8. Safety and rules

- [ ] Film only yourself for now. No classmates until the school has approved it.
- [ ] Warm up first.
- [ ] Stop at once if anything hurts.
- [ ] Keep the floor clear and the stool steady, and keep boards from sliding.
